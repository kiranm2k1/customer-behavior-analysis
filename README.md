# 🛍️ Customer Behavior Analysis 

## 📌 Project Overview An end-to-end data analytics project analyzing customer shopping behavior using Python, MySQL and Power BI. 

## 🛠️ Tools Used - **Python & Pandas** — Data cleaning & EDA - **MySQL** — Data storage & business queries - **Power BI** — Interactive dashboard 

## 📊 Dashboard Highlights - 3.9K Total Customers - $59.76 Average Purchase Amount - 3.75 Average Review Rating - Revenue & Sales by Category and Age Group 

## 💡 Business Questions Answered - Which category generates the most revenue? - Are repeat buyers more likely to subscribe? - What age group contributes the most revenue?
